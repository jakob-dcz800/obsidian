# Downcast 

In class-based programming, **downcasting**, or type refinement, is the act of casting ("Type conversion") a _base_ or _parent_ class reference, to a more restricted derived class ("subtyping") reference. 
This is only allowable if the object is already an instance of the derived class, and so this conversion is inherently fallible.
