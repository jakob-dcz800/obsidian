# Lister

**Bitonisk (bitonic)** betyder, at sekvensen først går i én retning og derefter skifter retning præcis én gang.

Eksempler:
- Bitonisk:
    - [1, 3, 7, 12, 9, 4, 2] (stiger → falder)
    - [9, 6, 4, 5, 8] (falder → stiger)
- Ikke bitonisk:
    - [1, 4, 2, 5, 3] (skifter retning flere gange)
