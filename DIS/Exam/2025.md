What are the ids of parent mammals which are not grandparents. 
```sqlite
SELECT
	p.parent_mid as gp,
	p.child_mid as pa
FROM 
	Parent p
WHERE NOT EXISTS (
	SELECT * 
	FROM Parent pp 
	WHERE pa =  p.child_mid
)
```
### test)
Select the names of cats that have zero children
```SQLite
SELECT
	m.name
FROM Mammal m
OUTER LEFT JOIN Parent p
	ON m.mid = p.parent_mid
WHERE
	m.sid = "cat"
	AND p.parent_mid = Null
```

### test)
Which pairs of species hunt each other but not themselves?
```sql
SELECT
	h.hunter_sid as hu,
	h.prey_sid as pr
FROM Hunts h
WHERE 
	h.hunter_sid != h.prey_sid
	AND EXISTS (
		SELECT * FROM Hunts hh 
		WHERE hu = hh.hunter_sid
		AND pr = hh.prey_sid
	)
```
