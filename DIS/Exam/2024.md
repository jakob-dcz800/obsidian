## 6.1 RA to SQL
Express the four RA queries from Question 5.3 in SQL.
### 1) ⚠️
What games (their ids) are owned by at least two different members?
```sqlite
SELECT
	o1.gid,
	COUNT(*) as member_count
FROM Owns o1 INNER JOIN Owns o2
	ON o1.gid = o2.gid
	AND o1.mid != o2.mid
WHERE member_count >= 2
GROUP BY gid
```

There is no need to cross join - members are not duplicated pr. gid
### 2)
Choose the games that are owned by more than one member
```sqlite
SELECT gid 
FROM Owns 
GROUP BY gid 
HAVING COUNT(gid) > 1
```

### 3)
Count games pr year. Then get the titles in the year with the most releases
```sqlite
❌ WRONG
SELECT
	title
FROM Games
WHERE year IN (
	SELECT year
	FROM Games
	GROUP BY year
	HAVING MAX(COUNT(*))
)
```
> - `HAVING MAX(COUNT(*))` is invalid because aggregate functions cannot generally be nested that way.

Correct:
```sqlite
SELECT title
FROM
	(SELECT MAX(cnt) AS CNT
	FROM 
		(SELECT 
			year, 
			COUNT(gid) AS cnt 
		FROM Game) AS YC
	) AS MAX
NATURAL JOIN
	(SELECT 
		year, 
		COUNT(gid) AS cnt 
	FROM Game) AS YC
NATURAL JOIN
Game
```

### 4)
What games (their titles) were published in the year which has the highest number of game copies (published that year) that are owned by club members?
```sqlite
WITH YC AS ( -- Each year, games pr. year for each owned copy
	SELECT
		year, 
		COUNT(gid) AS cnt 
	FROM Game 
	NATURAL JOIN Owns
),

MAX AS (
	SELECT MAX(cnt) AS cnt
	FROM YC
)

SELECT 
	title
FROM
	MAX -- works as a filter when joined with YC, 
	-- since all common cols are matched
	NATURAL JOIN
	YC
	NATURAL JOIN
	Game
```
## 6.2 Write SQL queries
### 1)
What is the average rating for each game (id)?

```sqlite
	g.gid
```

### 2)
What is the average rating for each game (id) that is owned by at least 5 club members?

```sqlite
WITH GamesOwnedByMoreThanFiveMembers AS (
	SELECT
		o.gid,
	FROM Own o
	GROUP BY o.gid
	HAVING COUNT(*) >= 5
)

SELECT
	AVG(r.rating) as avg_rating,
	g.gid
FROM GamesOwnedByMoreThanFiveMembers g NATURAL JOIN Rating r
GROUP BY g.gid
```

OR
```sql
SELECT gid, AVG(rating) AS avg
FROM Rates
WHERE gid IN (SELECT gid FROM Owns GROUP BY gid HAVING COUNT(mid) >= 5)
```

### 3)
Which designers have published at least 10 games rated above 8 on average?
```sqlite
WITH DesignersWithAtLeastTenPublishedGames AS (
	SELECT
		g.designer,
	FROM Games g
	GROUP BY g.designer
	HAVING COUNT(*) >= 10
)

SELECT
	AVG(r.rating) as avg_rating,
	g.gid
FROM DesignersWithAtLeastTenPublishedGames g NATURAL JOIN Rating r
WHERE avg_rating > 8
GROUP BY g.gid
```

OR
```sqlite
SELECT designer
FROM Game
	NATURAL JOIN
	(
		SELECT gid 
		FROM Rates 
		GROUP BY gid 
		HAVING AVG(rating) > 8
	) AS HighRaters
GROUP BY designer
HAVING COUNT(gid) >= 10
```

### 4)
Missing out! 
Create a materialized view showing for each member (their name), the games (their titles) they own but have not rated.

- Own relation
	- Member
	- Game
	- Is there a rating?

```sqlite
CREATE MATERIALIZED VIEW MemberOwnedButUnrated AS
SELECT
	m.name,
	g.name
FROM Owns o
NATURAL JOIN Member m
	ON m.mid = o.mid
NATURAL JOIN Game g
	ON o.gid = g.gid
WHERE o.gid NOT IN (
	SELECT 
		*
	FROM Rates r
	WHERE r.gid = o.gid
)
```
