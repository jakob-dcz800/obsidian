# Vandermondematricen

![[Pasted image 20250429200611.png]]

## Fact

Rangen af $V_{m,n} = min(m, n + 1)$
• Hvis $m ≤ n + 1$ så gælder $rank(V_{m,n}) = m$
• Hvis $m > n + 1$ så gælder $rank(V_{m,n}) = n + 1$

## Theorem

Lad punkterne $(x_1, y_1), . . . ,(x_m, y_m)$ være givet.

• Hvis $m < n + 1$ er der **uendeligt mange** polynomier af grad højst n som går igennem punkterne 
• Hvis $m = n + 1$ er der **netop et** polynomium af grad højst n som går igennem punkterne 
• Hvis $m > n + 1$ er der **intet eller netop et polynomium** af grad højst n som går igennem punkterne
