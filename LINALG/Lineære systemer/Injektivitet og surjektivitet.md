# Injektivitet og surjektivitet

## Definition

![[Pasted image 20250506214839.png]]

Disse definerer hvordan [[Lineære transformationer#Definition|lineære transformationer]] kan opføre sig.

Hvis det KUN er nulvektoren som bliver afbilledet over i 0, er den lineære transformation **injektiv**
Den er **surjektiv** hvis vi kan få en vilkårlig vektor i m'te frem i billedet T af x

Hvis en lineær transformation både er injektiv og surjektiv, kalder vi den for **bijektiv**
