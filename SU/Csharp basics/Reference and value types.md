# Reference and value types

## Ref
• Both reference and output parameters act as aliases,  
or other names, for the same memory location  

• The keyword `ref` is used to indicate a reference  
parameter; The keyword `out` is used to indicate an  
output parameter

When you use a reference parameter to a method, the  
parameter must be assigned a value before you use it  
in the method call
## By value

When you use a value parameter in a method  
header, you indicate the parameter’s type and  
name, and the method receives a copy of the  
value passed to it
## Delegate

A delegate is a reference type to a method with a  
return type and a parameter list

Allows passing a method to another method
(higher order function)
