Hver forgrening er en type af resource som kobler sig til metoden.
- begreber
- principper
- retningslinjer: faser
- teknikker som kan bruges i faserne

## Vidensområder

Under forundersøgelsen **skal** der udvikles viden inden for 3 områder.
Denne viden skal opnås ved:
- Konkrete erfaringer vor vidensområdet opleves
- Abstrakte produkter såsom beskrivelser og/eller modeller.

|                     | Brugerens nuværende arbejdspraksis                               | Nye IT anvendelser                                | Teknologiske muligheder                         |
| ------------------- | ---------------------------------------------------------------- | ------------------------------------------------- | ----------------------------------------------- |
| Abstrakt viden      | **Relevante beskrivelser af brugernes nuværende arbejdspraksis** | **Visioner og designforslag**                     | Overblik over teknologiske muligheder           |
| Konkrete erfaringer | **Konkrete erfaringer med brugernes nuværende arbejdspraksis**   | **Konkrete erfaringer med de nye IT anvendelser** | Konkrete erfaringer med teknologiske muligheder |
Det drejer sig om:
### Brugerens nuværende arbejdspraksis

- Produkter og serviceydelser som leveres
- Hvorfor, hvordan opgaver udføres samt iboende problemer
- Hindringer for forretningsmæssige mål - mål som skal kunne realiseres på baggrund af undersøgelsen.
- Ledelsesstrategier og stil
- Brug af IT-systemer og anden teknologi
- Relationer til andre ansatte, kunder og leverandører
### Nye IT anvendelser

- IT og anden teknologi
- Måder at organisere arbejde på
- Behovet for eventuelle nye brugerkvalifikationer
### Teknologiske muligheder
- Generel viden om IT, herunder relevante standardsystemer
- Mulige måder at organisere arbejdet på ifm. forskellige typer af IT systemer
- Konkrete erfaringer med ovenstående ud fra tidligere IT projekter.
