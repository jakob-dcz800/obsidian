Here we need to talk about **cardinality** of a set, which is basically the size of the set. 
The cardinality of a set is denoted by $|A|$.

## Finite Sets

Consider a set $A$. If $A$ has only a finite number of elements, its cardinality is simply the number of elements in $A$. For example, if $A=\{2,4,6,8,10\}$, then $|A|=5$. 
Before discussing infinite sets, which is the main discussion of this section, we would like to talk about a very useful rule: 
the **inclusion-exclusion principle**. For two finite sets $A$ and $B$, we have
$|A∪B|=|A|+|B|−|A∩B|$
